# Android race test, 0.1.2

The 0.1.1 device test reached menus and Career cinematics, with cars visible but
missing world geometry. Quick Race was still killed. Android reported LOW_MEMORY
(PSS 776 MB, RSS 877 MB). The first session also recreated its swapchain 1,430
 times and recorded 12 rejected graphics-pipeline variants. These are separate
observations; the shader linker failure's driver-level cause is unconfirmed.

## Changes

* Keep usable Android swapchains on VK_SUBOPTIMAL_KHR. Resize, out-of-date and
  lost surfaces still recover normally.
* Compile ordinary vertex draws separately from rectangle expansion. Ordinary
  draws use Vulkan's supplied index and avoid rectangle temporary arrays.
* Emit constant register initialization and the four memory redirect checks
  explicitly, preserving their order and bounds.
* Build glslang's pinned SPIR-V optimizer and optimize/validate Android shaders.
  Distinguish the new cache format from previous unoptimized binaries.
* On VK_ERROR_UNKNOWN, try optimized SPIR-V 1.3 once after optimized 1.5. Log
  recovery; memoize final failures. Do not retry memory or device-lost errors.
* Store bounded pipeline failure captures under the session name.

## Validation

Signed optimized ARM64 build; synthetic translator regression test. All 24
original captured SPIR-V modules passed Vulkan 1.2 validation. Revised private
captures compiled/validated (27 stage/primitive combinations). Twelve failed
pairs were checked at three primitive modes and two Vulkan targets: 72 pairs,
144 modules. For the offline GLSL cross-stage linker only, varying names were
normalized to match; runtime Vulkan modules retain their explicit locations.
Eight modules generated by the actual translator passed optimized compilation
and SPIR-V validation. This does not prove Adreno pipeline creation or driving.

## Device acceptance

Install over the previous APK; retain ISO access. Capture logs before launch.
Use the same Quick Race and default 720p. Reach countdown, drive two minutes,
finish a race, then enter another race. Record memory at menu/load/driving,
world geometry, controls, audio and exit information before relaunch if killed.
